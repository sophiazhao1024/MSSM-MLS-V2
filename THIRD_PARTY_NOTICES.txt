Scientific starting point
-------------------------
Jie Ren, Lei Wu, Jin Min Yang, Jun Zhao,
Exploring supersymmetry with machine learning,
Nuclear Physics B 943 (2019) 114613.
DOI: 10.1016/j.nuclphysb.2019.114613

This repository is a new software implementation. The historical path is an
independent reconstruction of published Model-4 information; the modern path
introduces explicitly new learning, selection and execution choices. Neither
path is recovered original author source. The paper citation does not identify
the paper authors as authors of this new code. xBIT was inspected as a framework
reference; its old Python scan classes are not copied into this repository.

HiggsSignals-derived driver
--------------------------
physics/fh_hs_driver.F derives its HB/HS conversion from the HiggsSignals 1.4.0
example HBandHSwithFH.F, originally identified as Tim Stefaniak, 06/03/2013.
The upstream GPL version 3 or later notice remains in the driver, and the full
licence text is also retained in physics/LICENSE-HiggsSignals.txt. Adaptations
include the FeynHiggs 2.13 API, explicit inputs/options/outputs and diagnostics.

External programs
-----------------
FeynHiggs, HiggsBounds, HiggsSignals, micrOMEGAs and CalcHEP are third-party
software. Full archives, generated third-party process code and compiled
binaries are not redistributed in this source package. scripts/setup_physics.py
retrieves the hash-pinned archives specified in configs/sources.lock.json.
Each downloaded package retains its own licence, copyright notices and
scientific citation requirements. Inspect and preserve them when building,
using or redistributing those packages. This project's GPL notice is not a
claim that every external package has the same licence.

micrOMEGAs 4.3.2 comes from a fixed HEPcodes historical mirror commit. The
original official tarball checksum was unavailable, so byte-identical
authentication against that original archive is not claimed. The commit and
archive SHA256 are recorded in configs/sources.lock.json.

Validation data and result scope
--------------------------------
The published initial1000 fixture is a sanitized derivative of saved true
physical evaluations, not new results generated by installing this release.
validation/data_provenance.json describes the source hashes and the removed
operational metadata. Numerical learning fields are preserved. Artificial
software fixtures remain separate from physical evidence.

Any newly published analysis should identify its settings, source versions,
physical configuration, target policy, budget and actual validation scope.
The released V5 single-development-seed experiment found4642 joint targets versus4248 for the stronger reconstructed NN reference and0 for random at20000 attempts each. It did not satisfy the original10% improvement gate; that historical outcome is retained. No completed independent multi-seed replication or reproduction of the article's approximately80% efficiency is claimed. See data/README.md and docs/method.md.
